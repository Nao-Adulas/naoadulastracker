# League of Legends Ranking (Pages Router - Padrão leaguestats)

## Como Executar

1. Instale as dependências:
   ```bash
   npm install
   ```

2. Crie o arquivo `.env.local` na raiz com sua chave da Riot:
   ```env
   RIOT_API_KEY=RGAPI-SEU-TOKEN-AQUI
   ```

3. Inicie o projeto em modo de desenvolvimento:
   ```bash
   npm run dev
   ```

4. Acesse `http://localhost:3000` no navegador.
